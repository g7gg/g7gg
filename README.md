### Big projects I worked on

**1. [Portsunami](https://github.com/g7gg)** | **`2016 – 2017`** | **⁷²**\
Portsunami is a high-speed CLI port-flooding tool built in C++, engineered for raw throughput and stability under extreme load. It stress-tests network boundaries, evaluates firewall behavior, and measures port-handling performance across large environments.

---

**2. [NetEye](https://github.com/g7gg)** | **`2016 – 2017`** | **¹⁰⁵ , ³²**\
NetEye is an internal-network mapping suite featuring 223 scanning, enumeration, and fingerprinting operations, all built in C++. The project emphasizes accuracy, adaptive probing, and multi-threaded discovery. I designed everything and worked on it solo.

---

**3. [Fort Martin](https://github.com/g7gg)** | **`2017 – 2019`** | **⁶⁹**\
Fort Martin is a military-style combat game developed in C++ and Unreal Engine. I built core gameplay systems, character physics, real-time AI behavior, and large-scale battle environments. The focus was responsiveness, balanced mechanics, and maintaining stable performance with heavy on-screen activity.

---

**4. [Nitrogen](https://github.com/g7gg)** | **`2020`** | **₁₁₈**\
Nitrogen is a Python-based encryption tool using a fully custom symmetric algorithm. I designed the algorithm from scratch, implemented the full encode/decode pipeline, and built a streamlined CLI around it. The goal was lightweight, dependency-free encryption for transferring sensitive files securely.

---

**5. [Stealth Spoofer](https://github.com/g7gg)** | **`2020 – 2021`** | **¹⁰¹**\
Stealth Spoofer is a hardware-identifier spoofing system for Windows written in C++. I implemented the driver-level logic, user-mode controller, and all layers responsible for safely rewriting hardware-exposed values. The project focused on low-level stability and invisibility during runtime.

---

**6. [Pulviq Music](https://pulviq.io)** | **`2020 – 2022`** | **¹¹⁴**\
Pulviq Music was the first Discord bot to feature real-time audio filters, powered by a custom TypeScript DSP engine. I built the complete architecture: audio pipeline, scalable infrastructure, and real-time processing layer. It operated thousands of live streams with low latency and high consistency.

---

**7. [Daisy](https://github.com/g7gg)** | **`2021`** | **¹²¹**\
Daisy is a high-performance hash-cracking utility written in C, packaged with over 12 billion password tokens in its built-in wordlists. I engineered the token indexing system, matching engine, and multi-threaded structure that enables extremely fast, memory-efficient processing on massive datasets.

---

**8. [Blackhole Tools](https://github.com/g7gg)** | **`2021 – 2023`** | **¹¹¹**\
Blackhole Tools is a suite of 70 GUI-based pentesting tools built in C++, C, and Python. I created the scanning engines, exploitation utilities, internal IPC system, and modular launcher framework. The project focused on delivering professional security workflows through a clean, unified graphical interface.

---

**9. [Opal Player](https://github.com/g7gg)** | **`2022 – 2023`** | **¹¹⁰**\
Opal Player is a terminal-based audio player supporting 28 audio formats with background playback capabilities. I built the decoding layer, terminal UI, playlist system, and asynchronous playback engine. It was designed for minimal CPU usage and high reliability.

---

**10. [Groovy Audio](https://groovy.audio)** | **`2024 – 2026`** | **¹⁰¹**\
Groovy Audio is a cross-platform audio engine supporting 50+ formats with real-time filtering, built using C, C++, and Python. I developed the DSP engine, UI framework, multi-threaded processing pipeline, and filter system. It represents years of engineering fit in a single year, for the cost of getting 3 hours of sleep every day for a year.
